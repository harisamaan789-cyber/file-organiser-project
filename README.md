# 📁 File Organiser (Python)

A simple Python automation tool that cleans and organises messy folders by sorting files into categories like images, documents, and videos.

---

## 🚀 Features
- Automatically sorts files into folders
- Supports common file types (images, documents, videos, etc.)
- Creates folders if they don’t exist
- Fast and easy to use

---

## 🛠️ How It Works
The script scans a selected folder and moves files into different directories based on their file type.

Example:
- .jpg, .png to Images/
- .pdf, .docx to Documents/
- .mp4  to Videos/

---

## ▶️ How to Run

1. Make sure you have Python installed
2. Download or clone this repository
3. Open the file and set your folder path:

```python
folder = "your_folder_path_here"
```

4. Run the script:

```
python main.py
```
